Creating and Configuring a GitHub System of Record Prerequisites A GitHub Personal Access Token, with scopes relevant to the entities that you want to sync into SGNL Basic Scopes: read:org , read:user , user:email , read:enterprise Entity Specific Scopes: Repository: public_repo Organization: admin:org Knowledge of your Enterprise Slug, available from Enterprise Settings (Profile –> Enterprise Settings, as an Enterprise Admin) in GitHub and is referenced with the Display Name If using GitHub Enterprise Server – the networking and service availability requirements for SGNL’s Adapters to connect
