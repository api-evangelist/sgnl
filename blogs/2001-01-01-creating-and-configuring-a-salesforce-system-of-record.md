Creating and Configuring a Salesforce System of Record Prerequisites An existing secure Salesforce API user - note the username of this User as it will be needed to configure SGNL A basic understanding of the Salesforce OAuth Client Credentials Flow Permissions Required A service account with permissions to read any of the objects that need to be synchronized to SGNL Permissions to access the Salesforce API Configuring Salesforce As a first step, identify your unique Salesforce sub-domain , this should form part of the URL you use to access salesforce, such as https://acme-corp.my.salesforce.c
