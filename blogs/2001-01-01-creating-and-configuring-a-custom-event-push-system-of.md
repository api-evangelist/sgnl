Creating and Configuring a Custom Event Push System of Record Custom Event Push Systems of Record enable real-time event streaming from external systems that do not support the Shared Signals Framework (SSF). This integration allows you to push arbitrary JSON events to SGNL, where they are stored in the graph and can be used to trigger CAEP Hub Actions and dynamic access control policies.
