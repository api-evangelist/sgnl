Creating and Configuring a Jira Data Center System of Record Prerequisites A Jira Data Center instance with an account that has the following permissions: Read access to Users Read access to Issues Read access to Groups For Username/Password authentication: Valid credentials for a user with the above permissions For Personal Access Token authentication: A valid PAT created in Jira Data Center Network connectivity requirements: SGNL requires inbound connectivity to your Jira Data Center instance on port 443 If inbound connectivity is not possible, consider deploying the SGNL On-Premises Connect
