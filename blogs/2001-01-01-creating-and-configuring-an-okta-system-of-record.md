Creating and Configuring an Okta System of Record Prerequisites An Okta User account with elevated privileges to read the Okta APIs Permissions Required Ability to add a new API Service Integration with scopes: okta.users.read, okta.groups.read, okta.apps.read Ability to generate an Okta API Key (if using an API Key method of authentication) Ability to read User, Group and/or App objects that are needed to be synchronized to SGNL Configuring Okta Using OAuth2 with an API Service Integration Login to your Okta Organization and select Applications from the left-navigation menu Choose API Service
