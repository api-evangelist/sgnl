Creating and Configuring a SCIM 2.0 Entity Push System of Record SCIM 2.0 Entity Push Systems of Record enable real-time entity synchronization by exposing a SCIM 2.0 compliant API endpoint that external systems can use to push User, Group, and Group Member entities directly to SGNL. This integration allows external systems to maintain real-time synchronization with SGNL’s graph, ensuring that access control decisions are based on the most current entity data.
